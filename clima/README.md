# Sistema de Consulta de clima

## Descrição
um site que permita ao usuário pesquisar uma cidade e visualizar:
    • Temperatura atual 
    • Umidade 
    • Velocidade do vento 
    • Data e hora da consulta 
    • Histórico das últimas pesquisas realizadas 
A aplicação consumirá dados de uma API pública de clima utilizando Fetch API.

## Funcionalidades
1. Busca de cidades
2. Consumo de API
3. Exibição dos dados
4. Histórico de pesquisas
5. Estatísticas
6. Grafico

## Tecnologias utilizadas
html, css e javascript

## Como executar
Abrir o arquivo index.html no navegador.
